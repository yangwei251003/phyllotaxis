# PHYLLO PROTO-02 制造资料

Ø180mm圆形、双层FR4、1.6mm、双面2oz，1套装配。Gerber.zip为铜层/阻焊/丝印/锡膏/外形/钻孔；BOM为167个器件；CPL为KiCad原生毫米、Y向上，原生角度。顶面165个SMD，底面J1/J2两个穿孔接头。全套要求另见docs/21-prototype-v02.md。

先核对8颗APXF100ARA271MF61G的正负极、capacitor-map.csv和正反面装配图，再按工厂坐标体系转换；黑色条纹为负极朝外。LED严格采用WS2812B-B-V6指定版本，按原厂MSL5a和回流条件管理。不允许未核对引脚/尺寸/时序的替代。J1固定脚虽然电气NC，仍按连接器要求装配。

可在单板外增加工艺边和光学基准，板内器件/孔位/外形保持不变。用户购买含全部SMT和底面插件焊接的PCBA；工厂导入核对属于加工步骤。已通过ERC、DRC与网表一致性，尚无焊接、通电或实板功能结果。
